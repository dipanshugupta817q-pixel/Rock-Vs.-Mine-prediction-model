# Rock vs Mine Prediction 🔍

## 📌 Overview
Machine Learning model to classify sonar signals as rock or mine.

## ⚙️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn

## 📊 Results
- Accuracy: ~81%

## 🚀 How to Run
Run the Python script after installing required libraries.
